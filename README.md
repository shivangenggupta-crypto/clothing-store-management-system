
# Clothing Store Management System

A portfolio project for managing clothing store operations, including products, inventory, sales, and sales forecasting.

## Goals

- Build a full-stack store management application.
- Track products, sizes, stock, and sales.
- Provide reports that help explain store performance.
- Add a sales forecasting feature using historical sales data.
- Keep development and deployment within free tiers.

## Planned stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Database and authentication: Supabase (Postgres)
- Forecasting: Python and scikit-learn; no paid AI APIs
- Deployment: Vercel Hobby
